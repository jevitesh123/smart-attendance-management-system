# Smart Attendance Management System

A professional Attendance Management System developed using Java Swing, JDBC, and MySQL.

## Features
- Admin Login
- Add Students
- View Students
- Search Students
- Update Students
- Delete Students
- Mark Attendance
- View Attendance
- Professional GUI

## Technologies Used
- Java
- Java Swing
- JDBC
- MySQL
- IntelliJ IDEA

## Project Type
Desktop Application
